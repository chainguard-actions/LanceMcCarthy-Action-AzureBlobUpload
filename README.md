# LanceMcCarthy/Action-AzureBlobUpload

A simple helper that will upload all the files in a source path to a destination path in a Blob container.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/LanceMcCarthy/Action-AzureBlobUpload](https://github.com/LanceMcCarthy/Action-AzureBlobUpload).
